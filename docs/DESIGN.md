# DESIGN — "Neon Rain" (pixel art)

Owner direction (2026-11-23): pixel art, cyberpunk, in the spirit of side-scrolling action games and rainy flying-car cities (owner's references: Huntdown, Cloudpunk). Every sprite, font and scene is OUR OWN — never copy characters, logos, tiles or layouts from those games. The first flat-vector attempt was rejected as "a 3-year-old's drawing"; the pixel city hero (`assets/hero.svg`, generated by `gen/pixel/hero.mjs`) is the approved reference for quality and style. Match it.

## 1. Medium and pipeline

- Each asset is generated by a Node script in `gen/pixel/` using the toolkit `gen/pixel/px.mjs` (RGBA `Layer`, PNG encoder, Bayer dithering `bayer()`, pixel `glow()`, 5×7 `FONT` + `text()`, seeded `rng()`).
- Output = an SVG whose content is `<image href="data:image/png;base64,...">` layers drawn at logical pixel size, with `image{image-rendering:pixelated;image-rendering:crisp-edges}` and `shape-rendering="crispEdges"`. The SVG `viewBox` is the logical resolution; `width/height` = logical × 2.5. So it stays sharp at any size and stays small (≤ 150 KB target, 1 MB hard limit).
- Motion = CSS on the layer groups: parallax `translateX` with `steps(n)` (whole-pixel jumps only — never sub-pixel smooth motion), sprite-sheet frames by `steps()` on a sheet inside a `clipPath`, opacity flicker for neon. No JS, no SMIL needed.
- Sprites are authored as palette-indexed string grids (one character per pixel, `.` = transparent) in `gen/pixel/sprites/*.mjs`, rendered by a shared helper. That makes them reviewable and editable as text.
- Reduced motion: the `@media (prefers-reduced-motion: reduce)` block stops animation and places moving things at a good-looking resting spot.

| Role | Hex |

| far skyline / rim | `#2b1756` / `#4a2a86` |

| neon cyan | `#3ff0e6` |

| text white / rain | `#f4ecff` / `#a9b6ff` |
| metal for sprites (dark → light) | `#1b1430 #2e2350 #4a3a7a #7a6ab0 #b8aee0` |

Lighting rule: the key light is neon from the RIGHT (pink/cyan rim on right edges), the ambient is deep purple. Every sprite gets a 1-px dark outline (`#05030c`), a lit right rim and dithered shading — no flat single-colour shapes.

## 3. Type

- Only pixel fonts drawn from `FONT` (5×7). Big titles = neon tube rendering (see the sign in hero.mjs: 2-px core `#ffe6f4`, 1-px pink edge, dithered halo). Small text at scale 1 in cyan/white on a dark translucent plate.
- Uppercase in the pixel font is the style of in-world signage here (diegetic signs), which is fine; README prose (alt text) stays sentence case.

## 4. Scene list and layout

GitHub content column ≈ 830–900 px desktop, ~360 px phone. All assets use logical width 400 (scaled to 100%).

1. `hero.svg` 400×168 — city + neon name sign + tagline (DONE, approved). Later: the owner's pixel character on the near rooftop.
2. `mech.svg` 400×168 — a rooftop workshop at night: a pixel dev board on a bench powers up and transforms into an original ~56-px-tall mech (unfold frames), idles (coil glow, visor scan, steam), folds back. Name: bench-mech. No franchise likeness.
3. `stats.svg` (generated daily) — in-world HUD: a holographic billboard on a building face with live numbers, language bars as neon tubes.
4. `projects/*.svg` — each project is a shop-front / billboard in the same street, clickable.
5. `contrib-game.svg` (generated daily) — the contribution calendar as a 53×7 grid of building windows; commit cells are lit windows by level; the mech patrols the rooftop and zaps windows.
6. Footer — a pixel subway-station sign "ENTER PORTFOLIO" and a YouTube billboard.

## 5. Quality bar (check every asset against the hero before showing the owner)

- Depth: at least 3 layers (sky/far, mid, near) with atmospheric fog.
- No flat fills larger than ~6×6 px without texture, windows, dithering or panel lines.
- Readable at 360 px wide: key text ≥ 7 logical px tall or repeated in alt text.
- Whole-pixel motion only; nothing flashes more than 3 times a second.
- If the orchestrator's own review says "toy", "flat" or "unfinished": stop and fix before the checkpoint.
